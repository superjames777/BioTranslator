<h1>BioTranslator</h1>
<p>BioTranslator is a translator and evaluator for DNA and mRNA. It is very basic, so more complex things like mutations are not supported. Made for fun so some bugs may be present, and I will try to fix them in my free time.</p>
<p>Features:</p>
<ul>
    <li>mRNA to DNA translator</li>
    <li>DNA to mRNA translator</li>
    <li>DNA evaluator</li>
    <li>mRNA evaluator</li>
</ul>
<p>Hopefully I will be able to add an amino acids translator later down the line, but as of now that is all!</p>
